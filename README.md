# ЖолБақылау AI

**Жол сапасы мен мемлекеттік қаражаттың ашықтығын бақылау жүйесі**  
«Жасанды интеллект — сыбайлас жемқорлықтың алдын алу құралы», Қазақстан, 2026.

Нақты RDD2022 YOLOv8n моделі → бейне дәлелі → GPS/учаске → адам тексеруі →
ресми жөндеу шарты → түсіндірілетін мониторинг есебі.

## Жаңа Arch Linux ортасында

Жүйелік пакеттерді/драйверлерді автоматты жаңарту талап етілмейді.
Python 3.11 немесе үйлесімді 3.12 және виртуалды орта қолданыңыз.
Тексерілген нұсқалар: Python 3.11.18, CPU torch 2.15.0, Ultralytics 8.4.216.

```bash
python3.11 -m venv .venv
.venv/bin/python -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m scripts.model_check
.venv/bin/python run.py
```

Python 3.11 жүйеде жоқ болса, `uv` арқылы жобаға оқшауланған интерпретатор:

```bash
python -m venv .bootstrap
.bootstrap/bin/pip install uv
UV_PYTHON_INSTALL_DIR="$PWD/.python" .bootstrap/bin/uv python install 3.11
UV_PYTHON_INSTALL_DIR="$PWD/.python" .bootstrap/bin/uv venv --python 3.11 .venv
.bootstrap/bin/uv pip install --python .venv/bin/python torch torchvision --index-url https://download.pytorch.org/whl/cpu
.bootstrap/bin/uv pip install --python .venv/bin/python -r requirements.txt
```

Бекітілген толық орта (браузер тексеру құралдарымен): `requirements-lock.txt`.
`pip install -r requirements-lock.txt` немесе `uv pip install --python .venv/bin/python -r requirements-lock.txt`.
Кейбір жаңа жүйеде OpenCV дөңгелегіне қажетті ортақ кітапхана болмаса, жүктеу қатесін
қараңыз; жүйелік өзгерісті өзіңіз шешіңіз. Осы Arch ортасында OpenCV және Chromium іске қосылды.

`ffmpeg` бар болса, браузерге H.264 бейне жасалады. Жоқ болса, белгіленген JPEG
дәлелдері қолданылады. Leaflet 1.9.4, интерфейске арналған Inter және PDF/дәлелге
арналған DejaVuSans жергілікті сақталған; OSM карта қабатына интернет керек.

## Қолдану

Фотосурет: **Суретті талдау** (`/images`) → JPG/JPEG/PNG/WEBP таңдаңыз → нәтиже.
Ең көбі 10 МБ, 16 мегапиксель. Бастапқы көрініс пен қазақша белгіленген нәтижені
салыстырып, PNG жүктей аласыз. Уақыт сүзгісі жеке фотосуретке қолданылмайды.
24 қарашадағы диагностика мен орындалған өзгерістер: `PROJECT_STATUS.md`.

1. **AI талдау** → MP4/MOV/AVI жүктеңіз. Түсірілім уақытын UTC+5
   бойынша беріңіз. Әдепкі 200 МБ, 180 секунд, 1 секунд сайын кадр.
2. Кезек пен прогресс көрінеді. Бір жұмысшы CPU арқылы ағынмен өңдейді;
   толық бейне RAM-ға жүктелмейді. Браузерді басқа бетке ауыстыруға болады.
3. Дәлелді қараңыз. Әкімші ретінде кіргенде «Расталған» немесе «Қабылданбаған» күйін негіздемемен таңдаңыз.
   «Дұрыс анықталды» / «Қате анықталды» батырмалары шешімді бөлек үлгілер жинағына сақтайды.
4. **Жол картасы** бөлімінде нақты учаскені қосыңыз. Бейне оқиғасын сол учаскеге
   тағайындаңыз. Учаскенің өзі оқиғаға координат бермейді.
5. Талдау аяқталғанда GPS CSV/GPX импорттаңыз, ығысу мен дереккөзді көрсетіңіз.
   GPS жоқ болса, жазба координатсыз сақталады.
6. **Ашықтық мониторингі** бөлімінде ресми шарт деректерін енгізіңіз, ресми құжатпен
   тексерілген күйін бөлек белгілеңіз. Жүйеде сатып алу API **қосылмаған**.
7. **Есептер** → учаске → есеп → PDF. Өтініш жобасын тексеріп, eOtinish-ке өзіңіз жібересіз.

### Детекция шегі және уақыт сүзгісі

Әдепкі `MODEL_CONFIDENCE=0.60` — **бастапқы мән, расталған оңтайлы шек емес**.
Шекті жүктеу/қайта талдау формасында өзгертіңіз. `TEMPORAL_MIN_HITS=2` және
`TEMPORAL_IOU=0.20`: қатар іріктелген екі кадрда бір санат пен қабысқан қорап қажет.
1 кадрлық тұрақсыз кандидат жойылмайды: бейне бетінде тексеруге қалады.
Адам растамайынша ол карта мен есепке кірмейді. Сүзгі тұрақты көрінетін люкті
семантикалық түрде танымайды және жылдам қозғалыстағы нақты ақауды өткізуі мүмкін.

Жаңа шек ескі нәтижеге автоматты қолданылмайды. Бейне бетіндегі «Қайта талдау»
жаңа нұсқа жасайды; ескі дәлелдер мен тексеру сақталады. Картада бір файлдың
соңғы аяқталған нұсқасы ғана есептеледі. Тексерілген үлгілер: `/reviews`,
жеке PNG файлдары: `instance/reviewed/`; ZIP тек соңғы қайтарылмаған шешімдерді береді.

Нақты өлшем: төрт RDD2022 суретінде 0.30 → 0.60 кезінде FP 3 → 0, бірақ
recall 66.67% → 16.67% төмендеді. Толық әдіс, шектеулер және люк мысалы:
[`docs/DETECTION_QUALITY_KZ.md`](docs/DETECTION_QUALITY_KZ.md).

### GPS форматы мен уақыт

```csv
timestamp,latitude,longitude
```

Осы тақырыптан кейін тек **өз сапарыңыздан алынған** нүктелерді қосыңыз.
timestamp: салыстырмалы секунд немесе `2026-11-20T10:00:00+05:00` тәрізді уақыт.
GPX: `trk/trkseg/trkpt`, lat/lon және timezone бар `time` міндетті.

**GPS уақыты = бейне секунды + ығысу**. Мысалы, бейненің нөлдік секунды GPS
тректің 12-секундына сәйкес болса, ығысу `+12`. Абсолютті timestamp алдымен
бейненің көрсетілген басталу уақытына қатысты секундқа айналады. Аралық 5 секундтан
аспаса, екі нақты GPS нүктесі арасында сызықтық интерполяция; трек сыртында немесе
ұзақ үзілісте **орын берілмейді**. Ең сенімді дәлел кадрының камера орны алынады.
GPS дәлдігі датчикке тәуелді; ақаудың қашықтығы/геодезиялық орны есептелмейді.

Бейне уақыты `frame_index / fps`. Прототип тұрақты кадр жиілігіне арналған.
Айнымалы FPS бейнесін алдын ала тұрақты FPS-ке түрлендіріп, GPS ығысуын қайта тексеріңіз.

### Түсіндірілетін ережелер

- **A:** аяқталу күнінен кейін адам растаған ақау. «Жаңадан пайда болды» деп кесіп айтылмайды.
- **B:** кемінде екі бейнеде, екі күнде расталған бақылау; тәуелсіздігін адам тексереді.
- **C:** құжатталған кепілдік мерзіміндегі расталған бақылау.
- **D:** шарт, мерзім, кепілдік немесе учаске дерегінің жетіспеуі.
- Расталмаған AI болжамдары бөлек көрсетіледі. Демо бейне A/B/C-ге кірмейді.
- Түсіндірме — AI детекцияларынан алынатын ережелік мәтін; генеративті LLM қосылмаған.
- Сыбайлас жемқорлық ықтималдығы, кінәлі тұлға, ойықтың нақты тереңдігі және
  қаржылық шығын есептелмейді.

### Қосымша діріл модулі

`/vibration`: CSV бағандары `timestamp,acceleration_x,acceleration_y,acceleration_z`,
қосымша `latitude,longitude,speed`. Уақыт секундпен, үдеу м/с², жылдамдық м/с.
Үдеу модулі және median/MAD шегі көрсетіледі. Ерекше шың — **ықтимал аномалия**,
ойық диагнозы емес. Дерек бұл нұсқада тек сұрау ішінде өңделеді, сақталмайды.

## Тексеру және ғылыми бағалау

```bash
.venv/bin/python -m pytest -q -m 'not integration'
.venv/bin/python -m pytest -q -m integration
.venv/bin/python -m pytest -q --junitxml=artifacts/pytest-results.xml
```

Бастапқы бағалау: класс сәйкес, IoU≥0.5, confidence≥0.30, бір GT қорабына бір болжам.

F1=0.6154. Бұл **Қазақстан жолдарындағы дәлдікті растамайды** және mAP емес.
Толық қораптар, шектер мен бастапқы нәтижелер `artifacts/evaluation-rdd2022-4.json` ішінде.

## Құпиялық және шектеулер

- Бір әкімші, signed session, CSRF, 10 қате кіруден кейін 5 минут шектеу,
  қауіпсіз UUID файлдары, кеңейтім+кодек+ұзақтық тексеруі, SQLAlchemy, HTML escaping.
- Дәлел/түпнұсқа/PDF тек кірген әкімшіге беріледі, `no-store`. `instance/` web static емес.
- Бірдей бейне SHA-256 бойынша танылып, қайталанған жүктеуге бар жазба қайтарылады.
- Жеке файлдар `instance/` ішінде; оны ашық репозиторийге/презентацияға қоспаңыз.
- Жариялау алдында бет пен нөмірді қолмен бүркемелеу көшірмесі:
  `python -m scripts.redact_image input.jpg rectangles.json output.jpg`.
  JSON: `[[x1,y1,x2,y2], ...]`. Бұл автоматты бет/нөмір табу емес; пайдаланушы барлық
  жеке деректі өзі тексеруі керек. Түпнұсқа өзгертілмейді.
- Бір процесс, бір ThreadPoolExecutor жұмысшысы. Redis жоқ. Бір мезетте бірнеше
  WSGI worker іске қоспаңыз. Процесс қайта басталса, аяқталмаған жұмыс failed болады.
- Бұл localhost демонстрация сервері. Қоғамдық орналастыруға HTTPS, жеке пайдаланушы
  рөлдері, сақтау/жою саясаты, сыртқы кезек және аудитті кеңейту қажет.
- Есеп — жасалған сәттің JSON көшірмесі. Жазба кейін өзгерсе, жаңа есеп жасаңыз.
- `PUBLIC_BASE_URL` PDF дәлел сілтемелерінің мекенжайын өзгертеді. Сыртқы оқырман
  жергілікті сервердегі жеке дәлелді автоматты аша алмайды.
