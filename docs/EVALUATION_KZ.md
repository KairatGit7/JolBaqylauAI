# Жергілікті ғылыми бағалау хаттамасы

## Қазіргі нәтижені дұрыс түсіндіру

`samples/rdd2022` ішіндегі төрт сурет — автор жариялаған test бөлігінен алынған
Қытай дрон суреттері. Таңбалар YOLO форматында автордан алынған. Біздің жаңа қолмен
таңбалауымыз емес. Барлығы 6 GT қорабы бар; болжам саны 7. Бұл көлем мен таңдау
Қазақстандағы, көлік камерасындағы немесе барлық ауа райындағы сапаны бағаламайды.
Үйрету/test тәуелсіздігін автордың бөлуінен тыс тексерген жоқпыз.

## Жаңа бағалау жиынтығын құру

1. Құқықтық негізі бар жергілікті суреттер жинаңыз. Сапарлар, маусымдар, жол түрлері
   бойынша әртүрлі дерек керек. Бір бейненің жақын кадрларын тәуелсіз сынақ санамаңыз.
2. Сапар бойынша train/validation/test бөліңіз. Осы алдын ала үйретілген модельге
   жергілікті test тек соңғы өлшем үшін қолданылады; confidence шегін test-пен баптамаңыз.
3. Әр суретке қолмен қорап салыңыз (мысалы, LabelImg). Күмәнді жағдайларды екінші
   белгілеушімен салыстырып, шешімін жазыңыз. Белгілеушіге модель болжамын алдын ала
   көрсетпеу растау қателігін азайтады.
4. Бір атаулы `.jpg` және `.txt` сақтаңыз. Қорап жоқ теріс мысалдың `.txt` файлы бос
   болады. Таңбасы жоқ сурет бағалауға кірмейді; ол автоматты теріс мысал емес.
5. Санат: `0 longitudinal_crack`, `1 transverse_crack`, `2 alligator_crack`, `3 pothole`.
6. Әр жол: `class center_x center_y width height`; координаттар сурет өлшеміне
   нормаланған `[0,1]`. Мысал формат қана: `3 0.5 0.5 0.2 0.1`.
7. Дерек көзі, лицензия/келісім, түсірілім құрылғысы, сапар идентификаторы,
   күн/ауа райы және белгілеуші шешімі туралы manifest сақтаңыз.

```bash
.venv/bin/python -m scripts.evaluate path/to/labeled-images \
  --confidence 0.30 --iou 0.50 \
  --provenance 'Жинақтың нақты шығу тегі мен бөлу хаттамасы' \
  --output artifacts/local-evaluation.json
```

## Метрикалар

Болжамдар confidence бойынша кему ретімен қаралады. Санат сәйкес әрі IoU≥0.5
болатын әлі сәйкестендірілмеген GT таңдалады. Бір GT тек бір болжамға сәйкеседі.

- TP: дұрыс санат және жеткілікті қорап қабысуы.
- FP: сәйкестігі жоқ болжам, соның ішінде қайталанған қорап.
- FN: табылмаған GT қорабы.
- Precision = TP/(TP+FP); Recall = TP/(TP+FN).
- F1 = 2TP/(2TP+FP+FN). Бөлгіш нөл болса JSON `null`, ойдан 100% қойылмайды.
- Жалпы micro және әр санат көрсеткіштері шығарылады.

Бұл **object detection** бағалауы. Ол classification accuracy, mAP немесе жол
оқиғаларының tracking дәлдігі емес. Ұсақ/ұзын жарықшақ қораптары IoU-ға сезімтал.
Агрегацияның бөлек бағалауы үшін уақыт бойынша физикалық ақау ID-лері керек;
мұндай таңбаланған тректер әзірге жоқ.

Қосымша зерттеу: көлеңкелі теріс мысалдар, қар/жаңбыр, бейне бұлыңғырлығы,
бір сапарға шаққандағы жалған дабыл, аппараттағы latency/RAM. Бұл өлшемдер қазіргі
есепте жасалған деп көрсетілмейді. Жергілікті сапа **әлі валидацияланбаған**.
