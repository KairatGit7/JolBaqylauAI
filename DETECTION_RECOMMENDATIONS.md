### До и после фильтрации: сохранённый отрезок 73.073–75.075 с

«Сырые боксы» здесь — выход YOLO после его confidence/NMS, до фильтров приложения.
Число боксов и число событий имеют разные знаменатели; ни то ни другое не является recall.

| imgsz / confidence | Сырые боксы, все 60 кадров | События после min_hits=2, все кадры | Боксы → прошедшие события, выборка 1 кадр/с |
|---|---:|---:|---:|
| 640 / 0.15 | 4 | 1 | 1 → 0 |
| 960 / 0.15 | 11 | 2 | 1 → 0 |
| 640 / 0.25 | 1 | 0 | 0 → 0 |
| 960 / 0.25 | 1 | 0 | 0 → 0 |
| 640 или 960 / 0.40–0.60 | 0 | 0 | 0 → 0 |

Ответ 0.330 на кадре 2231 при 640/0.25 пропущен выборкой каждого 30-го кадра;
при 960/0.25 ответ 0.260 появляется на кадре 2219. Оба одиночные.
Покадровая обработка сохраняет эти ответы, но не делает их правильными;
temporal-повторяемость тоже не отличает яму от устойчивой разметки или люка.

## Два рекомендуемых профиля для последующей проверки

Это **стартовые гипотезы**, не валидированные оптимумы или гарантия улучшения.

| Параметр | Высокая полнота: поиск кандидатов | Сбалансированный: меньше очевидного шума |
|---|---|---|
| Confidence | **0.15** | **0.40** |
| Inference imgsz | **640** | **960** |
| Обработка видео | **Каждый кадр**, прежде всего короткие офлайн-фрагменты | **Каждый кадр**, прежде всего короткие офлайн-фрагменты |
| Temporal-отсев | **Выключен**: min_hits=1; группировка дублей допустима | **Включён**: min_hits=2, IoU=0.20, gap ≤ 1.1 интервала обработки |
| Проверка человеком | Обязательна для всех кандидатов | Обязательна; высокий score не исключает люк |

**Почему так:** 0.15/640 сохраняет слабый кандидат `000099`, потерянный при 960,
и менее затратен по размеру входа; 0.10 не дал дополнительных pothole-боксов на
этих фотографиях. 0.40/960 убирает наблюдавшийся низко-/среднеуверенный шум,
сохраняя два правдоподобных положительных примера. Это локальные наблюдения,
а не доказательство лучшей полноты/precision на новых дорогах.

Сбалансированный temporal-профиль может снова скрыть настоящую кратковременно
видимую яму: одиночные кандидаты нужно оставлять доступными для ручного просмотра.
Для фото temporal не применяется. Сохранять letterbox, все четыре класса и обычный
YOLO NMS; не вводить дополнительную фильтрацию классов по этим данным.

Текущая среда — CPU PyTorch: скорость 960, realtime и расход памяти GTX 1050 Ti
не измерены. Интервал 0.1–0.2 с мог бы уменьшить стоимость, но такая выборка здесь
не сравнивалась и не рекомендуется как уже проверенная замена покадровому режиму.
Покадровый режим и 960 проверены диагностическим кодом; таблица не является
готовой заменой `.env` или заявлением о наличии новых controls в приложении.

## Что ещё необходимо подтвердить вручную

**В дорожном видеосегменте нельзя надёжно подтвердить восстановление настоящих ям.**
На просмотренных боксах видны ложные цели; остальные предполагаемые дефекты
ограничены качеством 360p. Метки RDD2022 — внешний эталон датасета, не независимое
подтверждение физической глубины дефекта или качества на местных дорогах.

Нужны точные таймкоды действительно пропущенных ям и просмотр соседних оригинальных
кадров человеком: отметить bbox, класс, видимость, люки/асфальтовые заплатки/тени/разметку и
неоднозначные случаи, затем сопоставить с уже сохранёнными предсказаниями.
Особенно проверить кандидаты кадров 2219/2231 и частичный бокс `000099`.
До этой проверки нельзя ранжировать профили по реальному recall видео или заявлять
численное улучшение точности. YOLO confidence не является калиброванной вероятностью правоты.

**Итог:** первый профиль — для ручного поиска пропусков, второй — для осторожного
снижения очевидного шума. Автоматически применять любой из них пока не следует.
