## Обновление: явные пресеты и ручная проверка

- В формах фото, видео и повторного анализа добавлен казахский селектор:
  **«Ағымдағы баптаулар»**, **«Толық анықтау»**, **«Теңгерімді»**.
- **«Толық анықтау»**: confidence 0.15, imgsz 640; каждый видеокадр,
  temporal-отсев выключен (min_hits=1). Группировка дублей остаётся.
- **«Теңгерімді»**: confidence 0.40, imgsz 960; каждый видеокадр,
  минимум два последовательных обнаружения одного класса с IoU-соответствием.
- Фото не проходят temporal-фильтрацию ни в одном режиме.
- По умолчанию сохраняется **текущая production-конфигурация**; выбор профиля
  действует только для конкретного запроса. Пресет, порог и размер сохраняются
  в SQLite, показываются в результате и учитываются при дедупликации видео.
  Старые анализы мигрированы как `default` / 640 без изменения прежних результатов.
- Для своих фото/видео доступны **«Дұрыс анықталды»**, **«Қате анықталды»**,
  **«Тексерілмеген»**. Можно отметить люк, разметку, тень, асфальтовую заплатку
  и другие причины. Чужие записи остаются недоступны; старые приватные материалы —
  только администратору. GPS и административные операции не открывались.
- Решения по фото сохраняются отдельно в `ImageReviewExample`, по видео —
  в существующем `ReviewExample`; история неизменяемая. AI-классы, score и bbox
  не перезаписываются человеческими решениями. Сброс сохраняет историю,
  но отзывает прежнюю метку из экспорта.
- Административный `/reviews/export` включает оба типа: исходные PNG,
  `reviews.jsonl`, bbox, source ID, пресет, размер, модель, решение и причину.
  Группировка по видео SHA-256 / хешу исходного PNG помогает избежать утечки
  дублей между dataset splits. Это частичные метки боксов, **не готовый полностью
  размеченный YOLO-датасет**: пропущенные дефекты и неоднозначные случаи нужно
  отдельно проверить перед подготовкой датасета.
- Исправлена обнаруженная регрессия: проверка неверных фото использует исходный
  Pillow decoder, не вызывая механизм установки optional HEIF-плагина YOLO.
- Резервная копия перед миграцией:
  `instance/backups/before-presets-reviews-2026-11-24.db`.

## История: предыдущий этап (задачи 1–3)

## 1. Доступ без обязательного входа

- `/`, `/analysis`, `/images` доступны без пароля; интерфейс остаётся казахским.
- Новые видео/фотографии и результаты доступны своей браузерной сессии и администратору.
  Дедупликация публичных загрузок ограничена владельцем; чужая копия файла не раскрывает
  существующее приватное видео и не заменяет его результаты.
- Старые записи без владельца остались в БД и доступны администратору.
- `/login` оставлен **только** для административных операций, истории/карты/отчётов,
  GPS и приватного архива. Обычный анализ и проверка своих новых загрузок не направляют туда.
- CSRF, защита приватных файлов и localhost по умолчанию сохранены.
- Linux/SSH/RustDesk, API-ключи, сетевые настройки не менялись.
- Перед миграцией создан `instance/backups/before-public-images-2026-11-24.db`.
